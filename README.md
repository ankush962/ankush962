## 🛠️ Featured AI Projects

### 📂 [RepoPilot](https://github.com/ankush962) — AI-Native Developer Workspace
- **Overview:** Architected a full-stack, multi-repository developer workspace (Next.js/React & FastAPI) that indexes codebases to answer system-level architectural queries using code-specific RAG context.
- **Tech Stack:** FastAPI, Next.js, PostgreSQL (`pgvector`), Redis, Ollama (`Qwen 2.5 Coder`), GitPython, Docker.
- **Key Features:** Robust authentication, background job queues with automatic retries, database migrations, rate limiting, security hardening, and Dockerized production deployment.

### 🧠 [Personal AI Assistant with Long-Term Memory](https://github.com/ankush962) — RAG-Based LLM App
- **Overview:** Built an intelligent assistant with a hand-built RAG pipeline (FastAPI, Chroma, SQLite) designed to retain and evolve user facts across sessions.
- **Tech Stack:** FastAPI, Chroma, SQLite, Groq, Ollama, Render.
- **Key Features:** Automated LLM-driven fact extraction and conflict-resolution engine (overwriting stale or contradictory data), relevance filtering, and automated regression testing scripts.
